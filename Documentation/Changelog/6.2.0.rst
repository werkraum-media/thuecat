Upgrade
-------

#. Run the database analyser and add the record type and venue columns of
   :sql:`tx_thuecat_tourist_attraction`, the table :sql:`tx_thuecat_meeting_room`, and the parking
   space and parent columns of :sql:`tx_thuecat_parking_facility`.
#. Run the upgrade wizard ``thuecat_meetingVenueType``, see :ref:`maintenance-meeting-venues`.
#. Run the attraction import configurations of each site. They fill the venue fields, import the
   meeting rooms and type the venues of sites without type categories.
#. Templates overriding :file:`TouristAttraction/Show` or :file:`TouristAttraction/ListItem` render
   no venue output until they call the venue partials, see :ref:`frontend-output-meeting-venues`.
