============
Installation
============

The extension can be installed via Composer, see :ref:`t3start:installing-extensions`.

The Composer package can be found at
`packagist.org <https://packagist.org/packages/werkraummedia/thuecat>`_.
The command is:

:shell:`composer require werkraummedia/thuecat`.

The site set should be configured in the site package. Information about the settings offered can be
found in :ref:`configuration`.
